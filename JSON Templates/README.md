# Templates

This directory contains JSON templates that demonstrate the required structure and formatting for the project's test-case definitions and run logs.

The data contained in these templates is **illustrative only**. Sample values, mathematical statements, expected answers, references, identifiers, metadata, and other content may be incomplete, placeholder-based, or factually, mathematically, or formally incorrect.

The templates should therefore be used only as structural examples for how the corresponding JSON files are to be filled. They must not be treated as validated benchmark data, verified expected results, or authoritative research content.

When creating actual files from these templates:

- Replace all sample and placeholder values with data appropriate to the specific case or run.
- Independently verify mathematical and formal-system content.
- Verify expected answers using the relevant Lean 4 oracle where applicable.
- Replace placeholder references and identifiers with valid sources.
- Complete metadata fields using the actual information for the case or run.

The validity of an actual benchmark file depends on the verification of its contents, not on the example data provided in these templates.
